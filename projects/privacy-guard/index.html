PrivacyGuard

A Python pipeline for detecting and masking selected sensitive regions in images, recorded video, and live streams before downstream use.

View the repositoryRead the fact-checked field note

What I built

PrivacyGuard combines object detection with configurable Gaussian blur, pixelation, and solid masking. The public repository covers image, video, camera, stream, API, and command-line workflows using Python, OpenCV, ONNX Runtime, and compatible detection models.

  • Local processingFrames can be processed without sending the visual data to a cloud inference API.
  • Multiple masking modesBlur, pixelation, or complete solid occlusion depending on the downstream need.
  • Configurable targetsFaces, people, and license plates when supported by the selected model and label mapping.
  • Inspectible implementationPublic code, examples, tests, and documentation under an MIT license.

Deployment context

I built PrivacyGuard independently as one component inside a larger CCTV system for a freelance client. It has been used with real footage, but the client, system, recordings, and operational details are confidential and are not reproduced here.

What the claim does—and does not—mean

Masking quality depends on detection quality. Missed or heavily occluded regions cannot be masked, blur is not encryption, and this project is not presented as automatic legal compliance. A historical controlled internal run reached approximately 25–30 FPS, but the retained project record does not define enough of the configuration to reproduce or generalize it. The result is not attributed to Raspberry Pi 4, a $35 computer, or arbitrary hardware.
