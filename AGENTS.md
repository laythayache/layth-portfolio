# Repository Instructions

## Required SEO, GEO, and online-presence workflow

At the beginning of every task in this repository, read these files completely:

1. `.agents/skills/online-presence/SKILL.md`
2. `.agents/skills/technical-seo/SKILL.md`
3. `.agents/skills/geo-ai-search/SKILL.md`

Apply all three skills proportionally to the task. A task does not need to create
SEO or GEO changes when the evidence does not support them, but it must not
silently bypass the identity, discovery, or AI-retrieval implications of a
public change.

Use one shared evidence base and prioritized backlog across the three skills.
Preserve these invariants:

- Never invent responsibilities, clients, metrics, production status, team
  attribution, recognition, or outcomes.
- Separate verified facts, reasonable inferences, unsupported claims, and
  experiments.
- Distinguish demonstrated work from future interests, shipped functionality
  from prototypes, and personal ownership from team contributions.
- Preserve confidentiality and do not expose private code, data, dashboards,
  infrastructure, credentials, or employer-owned implementation details.
- Treat local validation, deployed behavior, indexing, ranking, AI citations,
  referrals, and conversions as separate outcomes.
- Do not promise rankings, sitelinks, AI answers, citations, or a knowledge
  panel.
- Recheck current platform guidance against primary official sources before
  relying on crawler names, structured-data requirements, or product behavior.
- Follow the repository's existing publication authorization. Do not treat an
  audit request as permission to publish or mutate external accounts.

If a required skill cannot be read, identify the missing path and do not claim
that the skill was applied.
